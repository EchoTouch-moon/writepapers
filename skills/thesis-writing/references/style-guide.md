# 聊城大学本科毕业论文格式规范

## 一、标题层级与字体

| Markdown | Word 层级 | 字体 | 字号 | 加粗 | 对齐 | 段前段后 | 首行缩进 |
|----------|-----------|------|------|------|------|----------|----------|
| `# 标题` | 章标题 | 黑体 | 小二 (18pt) | 是 | 默认 | 7.8pt | 无 |
| `## 标题` | 二级标题 | 黑体 | 三号 (16pt) | 是 | 默认 | 7.8pt | 0pt |
| `### 标题` | 三级标题 | 黑体 | 四号 (14pt) | 是 | 默认 | 7.8pt | 0pt |
| `#### 标题` | 四级标题 | 黑体 | 小四 (12pt) | 是 | 默认 | 7.8pt | 0pt |

## 二、正文

- 字体：宋体，小四 (12pt)
- 行距：固定值 20pt
- 首行缩进：2字符 (24pt)
- 对齐：两端对齐 (justify)

## 三、特殊段落

### 图表标题
- 格式：`> 图2-1 xxx` 或 `> 表3-1 xxx`
- 字体：宋体，小四 (12pt)
- 对齐：居中 (center)
- 图标题在图下方，表标题在表上方
- 引用格式：不使用"如下图"，使用"如图2-1所示"

### 关键词
- 格式：`关键词：关键词1；关键词2；……关键词n`
- 字体：宋体，小四
- 3-5个关键词，用分号分隔

### 参考文献
- 编号格式：`[1]` `[2]` ...
- 正文引用：使用 `[@citekey]` 占位符（自动转为 field_anchor）
- 模板中已有引用格式示例，参照即可

## 四、行距与间距

| 元素 | 行距 | 段前 | 段后 |
|------|------|------|------|
| 章标题 | 固定 20pt | 7.8pt | 7.8pt |
| 二级标题 | 固定 20pt | 7.8pt | 7.8pt |
| 三级标题 | 固定 20pt | 7.8pt | 7.8pt |
| 正文 | 固定 20pt | 0 | 0 |
| 图表标题 | 固定 20pt | 0 | 0 |

## 五、编号规则

- 图编号：按章编号，如"图2-1"表示第二章第1个图
- 表编号：按章编号，如"表3-2"表示第三章第2个表
- 公式编号：按章编号，如"(4-1)"表示第四章第1个公式
- 参考文献编号：全文顺序编号 [1], [2], ...

## 六、Markdown 速查

```
# 1 绪论                    → 章标题（黑体小二）
## 1.1 研究背景              → 二级标题（黑体三号）
### 1.1.1 具体方面           → 三级标题（黑体四号）
正文段落内容 [@wang2022]    → 正文（宋体小四，首行缩进2字符）
**重点文字**                → 加粗
> 图2-1 系统架构图          → 图标题（居中）
> 表3-1 性能对比            → 表标题（居中）
```
