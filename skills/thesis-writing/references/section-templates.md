# 各章节写作模板

## 通用原则
- 每段 150-300 字，不超过 400 字
- 段落间逻辑衔接（不要罗列式堆砌）
- 引用密度：每章至少引用 3-5 篇文献
- 禁止大段引用原文（用自己的话概括）

---

## 1 绪论（~3000字）

### 子节结构
```
## 1.1 研究背景（~600字）
## 1.2 研究目的与意义（~500字）
## 1.3 国内外研究现状（~1200字，引用最密集）
## 1.4 研究内容（~400字）
## 1.5 论文组织结构（~300字）
```

### 1.1 研究背景
- 从宏观到微观：行业背景 → 技术趋势 → 具体问题
- 引出研究课题的必要性
- 可引用权威数据/报告

### 1.2 研究目的与意义
- 理论意义：对学术领域的贡献
- 实际意义：对产业/应用的价值
- 与前人工作的差异

### 1.3 国内外研究现状
- 分 2-3 个技术方向综述
- 每个方向：国外进展 → 国内进展 → 现有不足
- 结尾引出本研究的切入点
- **注意**：本章是引用最集中的章节，但篇幅不超过全文 1/3

### 1.4 研究内容
- 概述论文要做的主要工作（3-5 点）
- 每点 1-2 句话

### 1.5 论文组织结构
- 按章节描述论文结构
- 每章一句话概括

---

## 2 相关技术（~3000字）

### 子节结构
```
## 2.1 相关理论（~800字）
### 2.1.1 理论1
### 2.1.2 理论2
## 2.2 相关技术（~1800字）
### 2.2.1 技术框架1
### 2.2.2 技术框架2
### 2.2.3 技术框架3
## 2.3 本章小结（~200字）
```

### 写作要点
- 介绍 2-4 个技术点或理论方法
- 来源：经典教科书、官方文档、核心期刊、ACM/IEEE 论文
- 技术选型的理由（为什么用这个技术）
- 如有公式，使用 `[EQUATION: LaTeX公式]` 占位

---

## 3 需求分析（~2500字）

### 子节结构
```
## 3.1 系统需求概述（~400字）
## 3.2 功能需求分析（~1200字）
### 3.2.1 核心功能模块1
### 3.2.2 核心功能模块2
...
## 3.3 非功能需求分析（~600字）
## 3.4 本章小结（~300字）
```

### 写作要点
- 功能需求：用用例图/功能结构图辅助说明
- 非功能需求：性能、安全性、可用性、兼容性
- 需求优先级排序

---

## 4 系统设计（~3000字）

### 子节结构
```
## 4.1 系统总体设计（~600字）
## 4.2 系统架构设计（~600字）
## 4.3 数据库设计（~600字）
### 4.3.1 概念结构设计
### 4.3.2 逻辑结构设计
## 4.4 详细设计（~1000字）
### 4.4.1 模块1设计
### 4.4.2 模块2设计
## 4.5 本章小结（~200字）
```

### 写作要点
- 架构图：> 图4-1 系统架构图
- 数据库：E-R图 + 表结构说明
- 详细设计：流程图 + 接口定义

---

## 5 系统实现与测试（~4000字）

### 子节结构
```
## 5.1 开发环境（~300字）
## 5.2 系统实现（~2500字）
### 5.2.1 模块1实现
### 5.2.2 模块2实现
### 5.2.3 模块3实现
## 5.3 系统测试（~1000字）
### 5.3.1 测试方案
### 5.3.2 测试用例与结果
## 5.4 本章小结（~200字）
```

### 写作要点
- 实现部分：关键代码片段 + 界面截图
- 代码不超过 10 行/片段，只展示核心逻辑
- 测试：功能测试 + 性能测试
- 用表格展示测试用例：> 表5-1 xxx测试用例

---

## 6 结论与展望（~1500字）

### 子节结构
```
## 6.1 工作总结（~800字）
## 6.2 不足与展望（~700字）
```

### 写作要点
- 总结：自己工作的优点、创新点
- 不足：诚实面对局限性
- 展望：改进方案和未来方向
- 如有类似系统，比较优劣

---

## 参考文献（~30-50条）

### 格式
```
[1] 作者. 文献标题[J]. 期刊名, 年份, 卷(期): 页码.
[2] Author. Title[C]//Conference. Year: Pages.
```

---

## 致谢（~300字）

- 单独占一页
- 感谢导师、同学、家人
- 真诚简短，不要夸张

---

## 摘要（中文 ~300字）
- 论文目的、方法、结果、结论
- 不含文献引用
- 独立自含（不读全文也能理解）
- 第三人称，被动语句

## Abstract（英文 ~200词）
- 与中文摘要对应
- 避免语法错误
- Keywords 用分号分隔
