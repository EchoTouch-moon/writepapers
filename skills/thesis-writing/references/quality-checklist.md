# 质量检查清单

## 检查点 1：生成前（上下文完整性）

- [ ] 研究主题已明确（来自 progress 文件）
- [ ] 前一章摘要已加载（用于连贯性）
- [ ] 当前章节模板已加载
- [ ] 参考文献列表已准备（至少 3-5 条可用）
- [ ] 样式规则已理解

## 检查点 2：预览后（内容质量）

### 段落数量
- [ ] 正文章节：10-30 个段落（不超过 35）
- [ ] 引言章节：8-15 个段落
- [ ] 结论章节：5-10 个段落

### 引用验证
- [ ] 所有 `[@citekey]` 引用的 key 在 literature_pool 中存在
- [ ] 没有幻觉引用（编造的 citekey）
- [ ] 引用密度合理（平均每 500 字 1-2 个引用）
- [ ] 绪论 1.3 节引用最密集（至少 5 个）

### AI 痕迹检测（必须避免）
- [ ] 无"此外"/"总而言之"/"至关重要"/"值得注意的是"
- [ ] 无"深入探讨"/"全面分析"/"提供了宝贵的见解"
- [ ] 无三段式排比（"首先...其次...最后..."连续3次以上）
- [ ] 无填充性过渡句（"随着...的发展"开头超过1次）
- [ ] 无重复句式（连续3段以相同句式开头）

### 格式正确性
- [ ] 章标题用 `#`（1个#）
- [ ] 二级标题用 `##`（2个#）
- [ ] 三级标题用 `###`（3个#）
- [ ] 正文无标题标记（直接写文字）
- [ ] 图标题用 `> 图X-X xxx` 格式
- [ ] 表标题用 `> 表X-X xxx` 格式
- [ ] 加粗用 `**文字**`
- [ ] 编号按章编排（图2-1, 表3-2 等）

### 内容完整性
- [ ] 覆盖章节模板中所有要点
- [ ] 无空洞段落（全是泛泛而谈）
- [ ] 有具体数据/案例支撑
- [ ] 图表有正文引用（"如图2-1所示"）

## 检查点 3：提交后（验证）

- [ ] `docx_diff` 显示预期数量的变更
- [ ] 没有意外的格式修改
- [ ] 进度文件已更新（status → completed）
- [ ] 增量保存文件已写入（thesis-draft-chN.docx）

## 检查点 4：跨章节一致性（每 2-3 章后）

- [ ] 术语一致（同一概念同一术语）
- [ ] 技术名词首次出现时有解释
- [ ] 章节间有逻辑衔接（不突兀）
- [ ] 图表编号连续无跳号

## 检查点 5：终审（Phase 10）

- [ ] 所有章节字数达标（偏差不超过 ±20%）
- [ ] 总字数 15000-25000 字
- [ ] 参考文献 30-50 条
- [ ] 摘要准确反映论文内容
- [ ] 致谢真诚简洁
- [ ] 图表全部被正文引用
- [ ] 无排版错误（标题层级正确）
